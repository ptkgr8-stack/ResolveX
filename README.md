# ResolveX

### Intelligent & Predictive Campus Issue Reporting and Prioritization System

ResolveX is an AI-powered campus issue management platform designed to transform traditional complaint reporting into an intelligent, predictive, and data-driven system.

Instead of treating every complaint equally, ResolveX analyzes reported issues, determines their severity and priority, routes them to the appropriate department, and identifies recurring problems to support preventive maintenance.

---

## 🚀 Key Features

- 🧠 AI-powered issue classification
- 📸 Image-based issue analysis
- 🚨 Intelligent priority scoring
- 📍 Location-based issue reporting
- 🔄 Duplicate issue detection
- 🏢 Automatic department assignment
- 📊 Real-time campus analytics
- 🗺️ Campus issue heatmaps
- 🔮 Predictive maintenance insights
- 📈 Recurring issue detection
- ⏱️ Issue tracking and resolution monitoring
